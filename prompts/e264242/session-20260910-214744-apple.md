*Result (22:39 CEST):* Branch `design/apple-visual-language`. The web fonts
are gone in favour of the system typeface (SF Pro on Apple devices), with a
type scale whose tracking and leading change with size. The colors now live
in one place: `lib/theme.ts` hands Recharts `var(--token)` strings, which SVG
resolves like any CSS value, so every chart follows dark mode and there is no
second palette to keep in sync. The series colors are Apple's system hues,
nudged in lightness until they pass the categorical checks (lightness band,
